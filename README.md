# Gumdrop Grand Prix

甜點卡丁車主題的 Hold & Win 老虎機試玩版。整款都在瀏覽器裡跑：數學結果由頁面裡的替身從預先算好的局數抽出，不連任何伺服器，也不涉及真錢（餘額只在記憶體裡，重新整理就回到起始值）。

**試玩：** https://serafuking.github.io/Gumdrop-Grand-Prix/

- 語言：網址加 `?lang=en`（預設）、`?lang=zh-TW`、`?lang=zh-CN` 或 `?lang=ja`。
- 電腦與手機（橫拿、直拿、摺疊機）都能玩，版面跟著視窗大小重排。

## 玩法

- 5×3 盤面、243 ways。按中間的旋轉鈕或空白鍵轉一局；旁邊是自動旋轉、加速、NITRO 加注與購買。
- 盤面有 6 枚以上金巧克力金幣就觸發 Pit Stop Respins：金幣固定、其餘重轉，共 3 次，每落下新的金幣補回 3 次。三排是三條賽道，某一排每多一枚金幣，那排的車就前進一格，整排填滿就衝線：冠軍那排的倍數 ×3、亞軍 ×2，填滿整個盤面再加 GRAND 獎池。
- 購買：PIT STOP（100 倍，直接以 6 枚金幣開始 Pit Stop）、POLE POSITION（300 倍，以 8 枚金幣開始、三條賽道都已起跑）；NITRO 加注（1.25 倍投注，金幣出現的機會加倍）。

## 內容

- `index.html`：遊戲本體（程式與樣式都已內嵌）

更新時用新的遊戲封包整個取代上述檔案。
